English

Brulion's own F-Droid repository: the official Android releases, the same APKs (and signature) as on GitHub. On your phone tap Add to F-Droid or scan the QR code; or add the address and fingerprint above by hand (F-Droid → Settings → Repositories → “+”). Linux, Windows and the browser version (a single HTML file you open from disk) are in the latest release.
