What is here

  1. The same APK files as in the releases on GitHub, with the same signature — Brulion installed from GitHub updates from here without uninstalling.
  2. The last three releases; new ones appear here right after they are published.
  3. Linux, Windows and the browser version are in Download above and in the latest release on GitHub.
  4. The browser version of Brulion @VERSION@ itself, in app/: it opens without downloading anything, works offline after the first visit and can be installed as an app from the browser’s menu. Your notes stay in that browser on your device — export them for a backup.
