# Skróty klawiszowe

Skróty na komputerze. Na telefonie wcięcia, przenoszenie, zadania, linki, tagi, polecenia, terminy i cofanie są w pasku narzędzi tuż nad klawiaturą (przytrzymaj przycisk Zadanie, aby wybrać status zadania; zobacz [[Pierwsze kroki#Pisanie na telefonie|Pisanie na telefonie]]).

## Ogólne
| Skrót | Działanie |
|---|---|
| Ctrl+K | paleta poleceń |
| Ctrl+O | szybkie przejście do strony |
| Ctrl+Shift+F | wyszukiwanie |
| Ctrl+J | dzisiejszy dziennik |
| Ctrl+N | nowa strona |
| Ctrl+Shift+N | szybka notatka do dziennika |
| Ctrl+Shift+B | dokumentacja Brulionu / powrót do poprzedniego notatnika |
| Alt+← / Alt+→ | wstecz / dalej |
| Ctrl+\ | panel boczny (szerokie okno) |
| F2 | zmiana nazwy strony |
| Ctrl+, | ustawienia |
| Ctrl+E | tryb źródła Markdown |
| Ctrl+Enter | w oknach: zatwierdź |

## Edycja bloków
| Skrót | Działanie |
|---|---|
| Enter | podziel blok / nowy blok (na początku tekstu: pusty blok nad nim, przy zadaniu puste zadanie) |
| Shift+Enter | nowa linia w bloku |
| Tab / Shift+Tab | wcięcie / wysunięcie z dziećmi |
| Alt+↑ / Alt+↓ | przeniesienie bloku z dziećmi |
| Ctrl+Enter | zmiana statusu zadania (po kolei) |
| Ctrl+Shift+Enter | menu statusu zadania (dowolny status albo bez statusu) |
| Ctrl+. | zwiń / rozwiń |
| Ctrl+Shift+C | skopiuj odwołanie do bloku `((…))` |
| Ctrl+Z, Ctrl+Y | cofnij / ponów |
| Ctrl+C / Ctrl+X | kopiuj / wytnij zaznaczony tekst bloku (dokładnie, z twardymi spacjami) |
| Ctrl+V | wklej: Markdown z kilkoma blokami staje się blokami, skopiowany punkt listy wkleja się bez drugiego znacznika, tekst ze strony WWW przychodzi z listami i nagłówkami; obraz lub pliki jako załączniki |
| Ctrl+A | zaznacz tekst bloku; drugi raz: wszystkie bloki strony |
| Shift+↑ / Shift+↓ | zaznacz tekst; na pierwszej / ostatniej linii, gdy zaznaczenie dojdzie do brzegu bloku: zaznacz ten blok i poprzedni / następny |
| Esc | zamknij podpowiedzi, potem zakończ edycję i zaznacz blok |
| / | menu poleceń |

## Zaznaczone bloki
Po Esc, Shift+strzałkach, Ctrl+A, Shift+kliknięciu albo przeciągnięciu myszą z bloku na blok zaznaczone są całe bloki razem z dziećmi (także zwiniętymi). Zaznaczenie widać jako jeden pasek. Ctrl+kliknięcie dobiera pojedynczy blok albo go wyjmuje — także z przerwami między zaznaczonymi blokami.

| Skrót | Działanie |
|---|---|
| Shift+↑ / Shift+↓ | powiększ albo zmniejsz zaznaczenie (w dzienniku także za brzeg dnia — na kilka dni naraz, wtedy tylko do kopiowania) |
| Ctrl+A | zaznacz wszystkie bloki |
| Ctrl+C | kopiuj (Markdown; w poczcie i edytorach dokumentów wkleja się sformatowane) |
| Ctrl+X | wytnij (kopiuj i usuń jednym krokiem cofania) |
| Ctrl+V | zastąp zaznaczone bloki tym, co jest w schowku |
| Delete / Backspace | usuń zaznaczone bloki (Ctrl+Z albo „Cofnij” w powiadomieniu przywraca je zaznaczone) |
| Tab / Shift+Tab | wcięcie / wysunięcie wszystkich (wcięcie tylko, gdy da się wciąć każdy; bez przerw w zaznaczeniu) |
| Alt+↑ / Alt+↓ | przeniesienie wszystkich razem (bez przerw w zaznaczeniu) |
| Ctrl+Enter | następny status zadania dla wszystkich (jeden zaznaczony blok: tylko on, bez dzieci) |
| Ctrl+Shift+Enter | menu statusu zadania — wybrany status dostają wszystkie |
| Ctrl+. | zwiń / rozwiń blok na końcu zaznaczenia |
| Ctrl+Shift+C | skopiuj odwołanie `((…))` do bloku na końcu zaznaczenia |
| Enter | edytuj blok |
| ↑ / ↓ | zaznacz sam poprzedni / następny blok |
| Esc | odznacz |

Gdy zaznaczone są co najmniej dwa bloki, u góry pojawia się pasek: Kopiuj, Wytnij, Usuń, Zaznacz wszystko i Więcej (Kopiuj jako tekst — zwykły tekst z punktorami, wcięcia, przenoszenie, status zadania). Fragmenty kilku akapitów skopiujesz, zaznaczając całe bloki, albo co do znaku w trybie źródła Markdown (Ctrl+E, *Więcej* ⋮ → „Źródło Markdown”). Więcej: [[Dokument i konspekt#Zaznaczanie i kopiowanie|Zaznaczanie i kopiowanie]].

Prawy przycisk myszy na bloku otwiera menu bloku (Kopiuj, Wytnij, Kopiuj jako tekst, Zaznacz, Kopiuj odnośnik, wcięcia, przenoszenie, usuwanie) — na bloku z zaznaczenia działa na całe zaznaczenie. Prawy przycisk w edytowanym tekście: Wytnij, Kopiuj, Wklej, Zaznacz wszystko. W przeglądarce Ctrl+Shift+C może otwierać narzędzia przeglądarki — wtedy odwołanie skopiujesz z menu bloku albo z palety poleceń (Ctrl+K → „Kopiuj odwołanie do bloku”). Więcej: [[Linki i odnośniki zwrotne#Kopiowanie odnośnika do bloku lub nagłówka|Kopiowanie odnośnika]].

Menu statusu zadania otwiera też prawy przycisk myszy na polu wyboru (na telefonie: przytrzymanie). Więcej: [[Zadania|Zadania]].

W dokumencie Backspace na początku punktu listy najpierw zdejmuje pole zadania, potem znacznik listy. Opis działania trybów: [[Dokument i konspekt|Dokument i konspekt]].
