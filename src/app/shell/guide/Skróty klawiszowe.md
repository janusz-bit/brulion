# Skróty klawiszowe

Skróty na komputerze. Na telefonie wcięcia, przenoszenie, zadania, linki, tagi, polecenia, terminy i cofanie są w pasku narzędzi nad klawiaturą (przytrzymaj przycisk Zadanie, aby wybrać stan zadania).

## Ogólne
| Skrót | Działanie |
|---|---|
| Ctrl+K | paleta poleceń |
| Ctrl+O | szybkie przejście do strony |
| Ctrl+Shift+F | wyszukiwanie |
| Ctrl+J | dzisiejszy dziennik |
| Ctrl+N | nowa strona |
| Ctrl+Shift+N | szybka notatka do dziennika |
| Ctrl+Shift+B | dokumentacja Brulionu / powrót do poprzedniego notatnika |
| Alt+← / Alt+→ | wstecz / dalej |
| Ctrl+\ | panel boczny (szerokie okno) |
| F2 | zmiana nazwy strony |
| Ctrl+, | ustawienia |
| Ctrl+E | tryb źródła Markdown |
| Ctrl+Enter | w oknach: zatwierdź |

## Edycja bloków
| Skrót | Działanie |
|---|---|
| Enter | podziel blok / nowy blok |
| Shift+Enter | nowa linia w bloku |
| Tab / Shift+Tab | wcięcie / wysunięcie z dziećmi |
| Alt+↑ / Alt+↓ | przeniesienie bloku z dziećmi |
| Ctrl+Enter | zmiana stanu zadania (po kolei) |
| Ctrl+Shift+Enter | menu stanu zadania (dowolny stan albo bez statusu) |
| Ctrl+. | zwiń / rozwiń |
| Ctrl+Z, Ctrl+Y | cofnij / ponów |
| Ctrl+V | wklejenie obrazu lub plików jako załączników |
| Esc | zamknij podpowiedzi, potem zakończ edycję i zaznacz blok |
| / | menu poleceń |

Zaznaczony blok (po Esc): Enter edytuje, Backspace lub Delete usuwa, strzałki przechodzą dalej, Tab, Alt+strzałki, Ctrl+Enter i Ctrl+Shift+Enter działają jak podczas edycji.

Menu stanu zadania otwiera też prawy przycisk myszy na polu wyboru (na telefonie: przytrzymanie). Więcej: [[Zadania|Zadania]].

W dokumencie Backspace na początku punktu listy najpierw zdejmuje pole zadania, potem znacznik listy. Opis działania trybów: [[Dokument i konspekt|Dokument i konspekt]].
