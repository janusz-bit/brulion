# Zasady code review

- PR maksymalnie 400 linii, inaczej dzielimy
- opis: co i dlaczego, link do zadania w Jirze
- autor nie merguje własnego PR bez approve
- komentarze grzeczne: "co myślisz o…?" zamiast "to jest źle"
- sprawdzamy: testy, nazwy, obsługa błędów, logi bez danych osobowych
- drobiazgi (styl) załatwia linter, nie człowiek
- odpowiedź na review w ciągu 24h
